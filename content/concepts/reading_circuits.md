A circuit diagram is a **map of connections**.

| symbol | name | meaning |
|---|---|---|
| line | **wire** | ideal conductor, 0 Ω. All points joined by plain lines form **one node** |
| ● | **node / junction** | where parts meet |
| ▭ | **resistor** | rectangle (IEC) or zig-zag — same part |
| long + short plate | **battery / source** | the long plate is the + side |
| ⏚ | **ground** | the agreed 0 V reference |
| ○ | **terminal** | where a meter or the next stage connects — usually the output |
| Ⓥ | **voltmeter** | two leads, shows the voltage between them; ideally draws no current |
| Ⓐ | **ammeter** | sits *in* the wire, shows the current through it |

A **branch** is one path between two nodes, with parts in it.

**Reading order that works:** find **ground** → find the **source** and its + side → trace the **current path** → find the **output terminal** → ask "which divider sets this node?"
